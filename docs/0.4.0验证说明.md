# 0.4.0 渐进检索验证说明

日期：2026-11-04。交付形式：本地开发构建 `dist/literature-library-0.4.0.xpi`。本轮不替用户安装插件、不启动或操作原生 Zotero、不修改真实文献库/队列，不消费真实 MinerU 或向量 API 配额。GitHub 更新清单仍指向既有发布版，不能依靠自动更新获得此开发构建。

## 已实施

- auto 默认为书目与摘要发现，fulltext 显式查正文；词法 BM25+ 与向量独立召回，按论文去重后融合。
- SQLite 独立保存轻量文献、文本块、向量、修订号和检索快照。旧数据按小批次本地投影迁移，保留原始行，事务失败回滚；重启可继续。首次发现检索不加载正文向量，后续增量同步。
- MiniSearch 7.2.0 固定版本随 XPI 打包，检索 Worker 经隐藏页面桥接；无外部服务、运行时安装或新模型。发现索引与正文索引分开按需加载，快照可恢复。
- 多主题批次最多 8 查询，独立结果/错误、过滤、布尔与短语约束、角色筛选、范围限制、排除已看文献、字符预算和游标。索引或查询变化使旧游标明确失效。
- 批读原始摘要/目录最多 20 篇，总字符预算内返回缺失/截断与剩余 ID。摘要缺失不作为排除依据。全文精读支持相邻片段，逻辑目录连接多页块而保留原 PDF 页码。
- literature_workspace 保存主题、候选、筛选理由、Agent 标注的阅读进度和证据立场、最近查询轨迹；从真实全文块保存原文、页码、版本。读取时核对来源变化/删除；不改 Zotero 集合或标签。
- GUI 新增调研主题查看页，可开摘要和原始证据，候选/证据独立翻页；筛选管理目前由 MCP 完成。
- MCP status 默认是覆盖/任务计数/有限 facets，不返回任务数组；view=jobs 单独分页。来源范围明确为派生库，非整个 Zotero。
- 修复编号参考文献及延续页误分类、无效年份截取；旧异常年份可从 Zotero 元数据恢复，否则保留未知。交互本地推理在当前批次结束后优先执行，查询向量按模型与原查询缓存。

## 实际验证

`npm run typecheck`、`npm test`、`npm run build` 和 `node scripts/check-release.mjs` 通过。

47 项核心与调研测试使用 Node 内置 SQLite 和独立内存数据库，未安装新 SQLite 依赖。既有队列、上传确认、凭据到期、模型与引用桥回归保留；新增覆盖：

- 旧数据迁移、重复启动、增量变更、删除投影、向量独立存储；发现与摘要 SQL 不读取完整 documents 行。
- 写入中途失败回滚，保留最后成功的原文和索引；向量加载期间修订变化会重新同步。
- 三主题多查询、批读摘要、缺失摘要、筛选排除、集内正文检索、相邻上下文、保存/恢复证据、跨主题补查、来源变更/删除。
- 词法与语义分支、科学短词、中文二元词、范围过滤、参考文献诱导、快照恢复、分页无重复及旧游标拒绝。
- 432 个不同任务的紧凑状态与分页详情；长摘要批读总预算、空候选集、查询向量缓存和交互优先级。

四套 headless Chromium 检查包括既有桌面/窄屏、持续刷新搜索框、队列跨页多选/右键/删除回归，以及新调研页、来源变更、摘要/证据打开和编译后 iframe/Worker 的词法、语义及快照恢复。测试使用演示数据，截图与报告输出在被忽略的 `test-output/`。

432 篇**合成文献**的暖词法检索记录在 `test-output/retrieval-report.json`，用于发现性能退化；不是实际用户库、原生 Zotero、磁盘冷启动或 Qwen 推理的性能数据，不据此承诺真实查询延迟。

安装包检查确认版本一致、打包检索 Worker 与 MiniSearch 许可证、不含测试宿主或凭据。运行时新增组件只有 MiniSearch，安装包仍约 6 MB。

## 尚待验收与边界

1. **新检索 Worker 的原生 Zotero/Gecko 兼容性未实机验证**。沿用既有推理页面桥接方式并通过 Chromium 后台测试，不能替代原生宿主验收。遵循用户不控制电脑的要求，本轮没有启动 Zotero。
2. **真实文献相关性没有人工标注评测**。尚不能报告真实 Recall@20/nDCG@10、全文证据 Precision@5 或达到系统综述完整性。新增检索结构让 Agent 可逐层核对，不保证 embedding 自动判断科学相关性。
3. **真实规模与后台入库并发性能未验收**。需单列首次迁移、冷/热索引、向量载入、推理/排队、MCP 输出和内存。大规模全文语义仍为范围内精确扫描，尚无 ANN。
4. **中文短语与章节角色有边界**。词法为二元切分，短语候选上做原文子串校验；无 NEAR。章节角色由标题规则识别，unknown 应保留供 Agent 判断。
5. **持久层仍保留原始 JSON**。默认发现和摘要读取已解耦，但单篇正文/目录读取仍使用该篇原始 DocumentRecord，包含其向量；后续可进一步拆读，避免大 PDF 单读开销。
6. 最近查询保留 20 条，get 返回最近最多 5 条预算内摘要；非完整可审计查询档案。工作区、候选与证据数量受限，不提供 Zotero 标签同步或自动文献总结。
7. 本轮未验证 Word/WPS 新的实际插入或刷新；既有原生确认边界不变。

## 更新与使用

在 Zotero「工具 → 插件 → 齿轮 → 从文件安装插件」选择新的 XPI 并按提示重启；首次启动本地迁移。Agent 端重新连接/刷新工具列表以发现新 schema，原 MCP 地址、令牌与配置不需要重配。具体调用示例见 [Agent 使用说明](Agent使用说明.md)。
