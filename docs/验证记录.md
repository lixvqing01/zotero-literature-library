# 0.1.0 验证记录

日期：2026-10-30。环境：Windows、Zotero 10.0.7、独立 `.test-profile` 和 `.test-data`。未安装到正式 Zotero 配置，也未修改正式文献库。

| 验证范围 | 结果 |
|---|---|
| TypeScript 类型检查与 XPI 构建 | 通过 |
| 9 项核心测试 | 通过：错误映射、90 天日期、旧 Key 响应隔离、页码、资源 URL、日志脱敏、中文检索、MCP、原生引用交接逻辑 |
| 隔离 Zotero 12 项集成检查 | 全部通过，见下表 |
| MCP 真实 HTTP | 未鉴权请求拒绝、Origin 防护、初始化、8 个工具、搜索和分层读取通过 |
| 管理页桌面/窄屏 | 1440×1000 和 390×844；文献详情层、密钥保存/清空、页面无 JS 错误通过 |
| 发布包核对 | 含本地 WASM；不含测试 harness、node_modules、原生扩展或内置用户 Key；另生成 SHA-256 文件 |

隔离 Zotero 中的 12 项检查：

| 检查 | 证据 |
|---|---|
| 插件启动与数据库 | 插件加载并读写独立 SQLite |
| 凭据生命周期 | 系统登录凭据保存、替换、清除；过期后旧响应不覆盖新 Key |
| 实际条目入库 | 创建隔离书目、读摘要并查询命中 |
| MCP 启用状态 | 端点从插件状态返回 |
| MinerU 模拟完整流程 | A0211 暂停 → 换 Key 恢复 → 上传一次 → ZIP 导入 → 第 2 页证据读取 → 重复入库跳过；活动任务强制操作不会覆盖 |
| 管理器原生窗口 | Zotero 中界面控件与文献表渲染 |
| 插件管理页入口 | about:addons 本插件卡片出现“打开知识库 / MinerU 设置”，可打开管理器 |
| 原生设置密钥状态 | 密码输入框与共享凭据状态初始化成功 |
| E5 真实本地推理 | 384 维有限数值，向量范数约 1 |
| Qwen 0.6B 真实本地推理 | 1024 维有限数值，向量范数约 1 |
| Qwen 向量写入与语义查询 | 向量存入 SQLite，语义检索命中；重启后使用本地模型缓存 |
| 自动条目通知 | 启用自动索引后新建条目，Notifier 自动完成入库 |
